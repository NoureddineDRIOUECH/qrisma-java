# Qrisma - Comment lancer le projet

## 📋 Prérequis

- **Docker** installé
- **Docker Compose** installé

## 🚀 Lancement du projet

### Démarrer l'application

```bash
docker-compose up -d
```

### Accès aux services

- **Frontend** : http://localhost:5173
- **Backend API** : http://localhost:8080

### Arrêter l'application

```bash
docker-compose down
```
